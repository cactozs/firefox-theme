## Basic hotkeys:
Ctrl + W — Close active tab<br>
Ctrl + T — Open new tab<br>
Ctrl + Shift + T — Restore closed tab<br>
Ctrl + PgUp — Focus tab on left<br>
Ctrl + PgDn — Focus tab on right<br>
F5 (or Ctrl + R) — Reload tab<br>
F6 — Focus URL bar<br>
Alt + <— (Alt + Left arrow) — Go back<br>
Alt + —> (Alt + Right arrow) — Go forward<br>
