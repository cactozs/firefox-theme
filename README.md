## Basic hotkeys:
Ctrl + W — Close active tab\n
Ctrl + T — Open new tab\n
Ctrl + Shift + T — Restore closed tab\n
Ctrl + PgUp — Focus tab on left\n
Ctrl + PgDn — Focus tab on right\n
F5 (or Ctrl + R) — Reload tab\n
F6 — Focus URL bar\n
Alt + <— (Alt + Left arrow) — Go back\n
Alt + —> (Alt + Right arrow) — Go forward
