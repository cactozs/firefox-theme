## Basic hotkeys:
Ctrl + W — Close active tab
Ctrl + T — Open new tab
Ctrl + Shift + T — Restore closed tab
Ctrl + PgUp — Focus tab on left
Ctrl + PgDn — Focus tab on right
F5 (or Ctrl + R) — Reload tab
F6 — Focus URL bar
Alt + <— (Alt + Left arrow) — Go back
Alt + —> (Alt + Right arrow) — Go forward
